Sobre o Muhsic

Muhsic é um projeto fictício desenvolvido para fins acadêmicos. Ele foi criado por Murilo N.B como parte do trabalho da faculdade e faz parte do grupo MPS — MapleProjectSeries.

Toda a interface, banco de dados simulado e sistema de planos foram projetados do zero em HTML, CSS e JavaScript puro — sem frameworks.
